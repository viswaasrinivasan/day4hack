# 🪪 My Digital ID Card

A personal profile card web page built during the **CSE Hackathon Bootcamp**.

🔗 **Live site:** https://[your-username].github.io/myidcard/

---

## ✨ Features

- 🖼️ Circular profile photo with hover animation
- ❤️ Like button that counts clicks
- 🐶 New photo button that loads a random dog image from a free API
- 🌙 Dark mode / light mode toggle
- ✏️ Edit your name, saved even after refreshing the page
- 🏷️ Skills shown as badges using a JavaScript loop
- 📱 Mobile-friendly design
- 🎨 Animated gradient background with a glass-style card

---

## 🚀 How to Run Locally

1. Download or clone this repository:
   ```
   git clone https://github.com/[your-username]/myidcard.git
   ```
2. Open the folder in VS Code.
3. Right-click `index.html` → **Open with Live Server**.
